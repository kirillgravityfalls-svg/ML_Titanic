# ML_Titanic
Анализ выживаемости пассажиров Титаника. Сравнение моделей машинного обучения. Стек: Python, Scikit-learn, Pandas.

Анализ выживаемости пассажиров Титаника
Сравнение моделей машинного обучения для предсказания выживаемости пассажиров.

Данные
Использован встроенный датасет Titanic из библиотеки seaborn.

Признаки

- pclass (класс пассажира)
- sex (пол)
- age (возраст)
- sibsp (количество сиблингов/супругов)
- parch (количество родителей/детей)
- fare (стоимость билета)
- embarked (порт посадки)

Созданные признаки:
- family_size (размер семьи)
- is_alone (одинок ли пассажир)
- has_child (есть ли дети)

Модели
Сравнивались две модели:
- Логистическая регрессия
- Случайный лес

Лучшая модель: Случайный лес (точность ~83%)!!!

Как запустить
Установи зависимости:
pip install -r requirements.txt
Запусти код:
python main.py

Результат
Модель показывает точность около 83%. 
Ключевые факторы выживания: пол, класс, стоимость билета.
